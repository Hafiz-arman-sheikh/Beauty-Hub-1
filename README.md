# Beauty Hub

A beauty and skincare website interface built as a front-end practice project.

## Features
- Product-focused sections
- Responsive page styling
- Bootstrap-based layout components
- Font Awesome icons

## Technologies
HTML5, CSS3, JavaScript, Bootstrap and Font Awesome.

## Run locally
Clone the repository and open `index.html` in a browser. If the page uses browser modules or external requests, run it through a local development server.
